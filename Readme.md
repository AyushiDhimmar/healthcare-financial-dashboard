# 🏥 Healthcare Financial Performance Review

An interactive Tableau dashboard analyzing healthcare financial data across departments, regions, and treatment types.

🔗 **Live Dashboard:** [View on Tableau Public](https://public.tableau.com/app/profile/ayushi.dhimmar/viz/Healthcare_Financial_Performance_Review_dashboard/Dashboard1)

---

## 📊 Dashboard Overview

This dashboard provides a comprehensive view of healthcare financial performance, enabling stakeholders to monitor revenue, expenses, and profitability across multiple dimensions.

### Key KPIs
| Metric | Value |
|--------|-------|
| Total Revenue | ₹ 33.0M |
| Profit Margin | 29.83% |
| Total Expense | ₹ 23.2M |
| Total Patients | 12,851 |

---

## 📈 Charts & Visuals

| Chart | Description |
|-------|-------------|
| **Regional Revenue Analysis** | Compares Expense vs Revenue across East, North, South, West regions |
| **Department Cost Efficiency** | Heatmap showing cost efficiency across 6 departments |
| **Profit Trend Analysis** | Line chart showing profit margin trends (2023–2024) by region |
| **Patient Mix by Treatment** | Horizontal bar chart showing patient distribution across treatment types |

---

## 🔍 Filters

- **Treatment Type** — Filter by Consultation, Diagnostics, Medication, Surgery, Therapy
- **Region** — Filter by East, North, South, West
- **Department** — Filter by Cardiology, Emergency, General Medicine, Oncology, Orthopedics, Pediatrics

## 📌 Data Description

The dataset contains healthcare financial records with the following fields:

- **Department** — Medical department name
- **Region** — Geographic region
- **Treatment Type** — Type of medical treatment
- **Total Revenue** — Revenue generated
- **Expense** — Total expenses incurred
- **Profit / Profit Margin** — Profitability metrics
- **Number of Patients** — Patient count
- **Cost Efficiency** — Cost per patient metric
- **Year / Date** — Time period (2023–2024)

## 🚀 How to Use

1. Open the [live dashboard](https://public.tableau.com/app/profile/ayushi.dhimmar/viz/Healthcare_Financial_Performance_Review_dashboard/Dashboard1)
2. Use the **filters** at the top to slice data by Treatment Type, Region, or Department
3. Hover over charts for detailed tooltips
4. All charts update dynamically based on filter selections
